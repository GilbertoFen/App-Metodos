# App de Métodos Numéricos

Esta aplicación, desarrollada con **Python** y **PyQt6**, permite realizar distintos métodos numéricos de forma sencilla e interactiva. Su interfaz gráfica facilita el ingreso de datos y la visualización de resultados, ideal para estudiantes y profesionales que trabajan con álgebra lineal y métodos numéricos.

## 🧮 Métodos Implementados

- **Método de Gauss-Jordan**
- **Gauss-Jordan particionado**
- **Método de la Secante**
- **Método de Jacobi**
- **Método de Intercambio**
- **Método de Gauss con técnicas de pivoteo**

## 🚀 Características

- **Interfaz gráfica** intuitiva y fácil de usar gracias a PyQt6.
- **Resultados detallados**: Se muestran pasos intermedios y resultados finales.
- **Ejecución sencilla**: No requiere instalación compleja, el ejecutable está listo para usarse.
